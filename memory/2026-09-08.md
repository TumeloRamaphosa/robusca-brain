## Method Note (for future-me)

Wrote the scanner to print only pattern name, file location, length, and a sha256 fingerprint — never the value. First version leaked a token into the terminal because `cut -d: -f1,2` on single-file `rg` output yields `linenum:match`, not `file:line`. **Redact at the source, and test the redaction on a known match before running it across repos.**

Liveness testing is what separates panic from triage: 4 of 5 real credentials found were already dead. Test before escalating, but never skip testing — the one that was live had been live for four months.
