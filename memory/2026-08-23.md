## Why studex-group.com didn't "just work"

`storage.ts` does `new Database("data.db")` — `better-sqlite3`, a native
`node-gyp` addon writing to a local file.

- **Vercel**: ephemeral, unshared function filesystem. Approving content would
  appear to work then silently revert.
- **Cloudflare Workers**: cannot load native addons *at all*. Hard isolate
  limit; `nodejs_compat` cannot fix it.

Checked current limits rather than assuming: Vercel's default function duration
is now **300s**, so the Higgsfield route's ~210s worst case actually fits. The
timeout was never the blocker — **the database is.**

Recommended split, in `os/war-room/DEPLOY.md`: `www.studex-group.com` = public
static site on Vercel (doesn't exist yet, needs building);
`warroom.studex-group.com` = the dashboard on a container host behind
**Cloudflare Access** (auth with zero application code — right answer for an
internal tool).
