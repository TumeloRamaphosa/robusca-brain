## Design decisions

**"The interface is a document, not a dashboard."** We sell institutional memory and
accountability, so it should read like a well-set financial report, not consumer SaaS.

Five rules: remove don't style; gold is a signal appearing once per view, never a
surface; all checkable data in monospace; hairlines not boxes; left-aligned always.

Forms (the "formful" part): label above input never placeholder-as-label; bottom rule
only, full box on focus; help text always visible not just on error; grouped under an
eyebrow with a rule above; one column.

Explicit anti-list: no cards-with-shadows, no status pills, no icons beside labels, no
purple/blue gradients (that's the 2023 AI aesthetic we're positioned against), no emoji.

Also specced how the discipline applies to agent output in WhatsApp where no CSS exists
— lead with the fact, CAPS as the eyebrow equivalent, under 200 words, silence when
there's nothing to say.

## Marketing prompts

Built around the anti-agent-washing wedge. Key constraints baked into every prompt:
never publish without explicit approval; every claim carries a receipt with T1/T2/T3
grading; **never use the word "agentic"**; forbidden claims list ("14 years of AI",
unevidenced client results, tokens, "replaces your team"); the measured format rules
(1–3s hook, hot-take/investigator for reach, proof-drop for saves, greenscreen 2.6x,
90s+ 31x, measure 3-second retention not views).

The Proof agent is the one that matters — it can REJECT, and it's the last line before
something embarrassing ships under a banner saying we don't overclaim.

Campaign brief: the ten-question Audit, published free and ungated, then we take it
ourselves on camera and publish the score including failures. Gated on Phase 0 (three
named deployments with hard numbers, our own audit scored, every claim mapped to a
receipt, June keys confirmed rotated).
